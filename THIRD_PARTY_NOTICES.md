# Third-Party and Source Notices

## RWTH 2021 source model and data

The current public executable SFOR branch uses published kinetic/final-yield equations and parameter values from:

**Pielsticker, Stefan; Gövert, Benjamin; Umeki, Kentaro; Kneer, Reinhold (2021).**  
*Flash Pyrolysis Kinetics of Extracted Lignocellulosic Biomass Components.*  
Frontiers in Energy Research, 9:737011.  
DOI: https://doi.org/10.3389/fenrg.2021.737011  
Article licence: Creative Commons Attribution 4.0 (CC BY 4.0).

Associated supplementary dataset:

**Pielsticker, Stefan; Gövert, Benjamin Maximilian; Umeki, Kentaro; Kneer, Reinhold (2021).**  
*Flash Pyrolysis Kinetics of Extracted Lignocellulosic Biomass Components – Supplementary Dataset.*  
DOI: https://doi.org/10.18154/RWTH-2021-05544  
Dataset licence: CC0 Public Domain Dedication.

## Redistribution boundary

This repository does **not** redistribute the raw RWTH supplementary archive. It contains source-derived parameterization/configuration metadata and independently implemented framework code required for the qualified example branch.

The source article and dataset should be cited when the SFOR branch is used.

## Other model families

Names such as CRECK, CPD/CPDSpatial, polymer branches, manure/dung branches, autothermal branches and co-pyrolysis branches may appear in model-eligibility metadata. Their presence does not mean that their external mechanisms, datasets or executable implementations are redistributed in this release.
